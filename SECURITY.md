# Security policy

## Supported versions

DJI Unchained VOC is alpha software. Security fixes are applied only to the current development line. Older source snapshots and APKs are preserved for reproducibility and are not maintained.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting feature for this repository when it is available. Include the affected version, Android version, hardware, impact, reproduction steps and a minimal proof of concept.

If private reporting is unavailable, open a short issue requesting a private contact channel. Do not publish exploit details, secrets, personal diagnostics, raw recordings or device identifiers in a public issue.

You should receive an acknowledgement within 14 days. A fix timeline cannot be guaranteed for this volunteer alpha project.

## Scope

Reports about the app's USB handling, media parsing, exported files, Android permissions, build pipeline or dependency chain are in scope. Vulnerabilities in DJI firmware, Android itself or unrelated third-party applications should be reported to their respective maintainers.
