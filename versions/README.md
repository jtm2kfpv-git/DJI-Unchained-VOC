# Version archive

These folders preserve the complete buildable Android source for every non-GUI release:

- `v0.1.0-hardware-confirmed` — original hardware-confirmed USB/video path.
- `v0.2.0` — aspect-ratio modes and stream statistics.
- `v0.3.0` — automatic reconnect and explicit connection states.
- `v0.4.0` — stream watchdog, staged recovery and diagnostics export.
- `v0.5.0` — permission-free raw H.264 recording.

Each folder is self-contained and includes its own Gradle wrapper, tests, README, and verification notes. Generated build caches and machine-specific SDK settings are excluded.

The v0.5.1 N3 GUI/branding experiment and logo are not part of this repository.
