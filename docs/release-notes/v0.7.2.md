# DJI Unchained VOC v0.7.2 — Recording and layout iteration

This prerelease is the current development build. It compiles, passes debug/release lint and passes 48 unit tests, but its new recording paths still require a short device regression test.

Highlights:

- fixes original-stream preview flicker by removing the recording document-picker round trip
- default lossless MP4 remuxing without re-encoding
- optional raw H.264 fallback in Advanced settings
- automatic original recordings in `Movies/DJI Unchained VOC`
- waits for valid dimensions, SPS, PPS and an IDR keyframe
- top-aligned disconnected artwork and bottom-aligned responsive controls
- 30/60 FPS Shorts selection with actual-FPS and timestamp diagnostics
- privacy-filtered diagnostic schema 3

The debug APK is ready for sideload testing. The release APK is deliberately unsigned. Keep v0.7.1 available as the hardware-tested fallback.

This unofficial alpha project is not affiliated with DJI and must not be used for flight safety.
