# DJI Unchained VOC v0.7.1 — Hardware-tested controls and diagnostics

This prerelease is the latest v0.7 checkpoint tested on the target Android 16 LineageOS phone with DJI Goggles N3.

Highlights:

- responsive portrait/landscape bottom control tray
- larger touch targets and simplified recording controls
- compact USB/video/resolution/FPS status strip
- independent aspect, display, output and recording-rate controls
- collapsible Advanced settings
- privacy-filtered diagnostic schema 2 with bounded timeline and expanded health metrics

The supplied test diagnostics showed stable 1920×1080 video, zero parser resynchronizations, zero recovery actions and zero raw-recorder drops.

Assets include the signed debug APK, unsigned release APK, SHA-256 manifest and complete source ZIP. This unofficial alpha project is not affiliated with DJI and must not be used for flight safety.
